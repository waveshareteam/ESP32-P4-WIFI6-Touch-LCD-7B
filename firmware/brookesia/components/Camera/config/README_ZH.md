# OV5647 ISP 白平衡

[English](README.md)

`ov5647_ipa.json` 基于传感器驱动的默认 IPA 配置，并添加了 gray-world AWB 模块。
`sdkconfig.defaults` 和本地 `sdkconfig` 都通过传感器驱动的自定义 IPA 配置选项选择
此项目配置文件。不要修改 `build/` 下的生成文件。

初始调试范围为绿色通道亮度 32 至 220，R/G 和 B/G 比值 0.5 至 1.5。此范围允许较暗的
室内中性色表面参与白平衡，同时排除过暗、过曝和颜色过饱和的样本。这些是初始值，并非
针对本摄像头模组校准后的测量值。红、蓝通道增益缩放保持为 1.0；增益更新阈值为 0.034。
现有 CCM、gamma、降噪和锐化设置保持不变。

视频驱动会按 `green_max * (1 + rg_max + bg_max)` 将绿色阈值换算为硬件亮度值。ESP32-P4
的上限为 1023。即使 IPA 更新 8 位绿色阈值，比值上限也必须有效：
`255 * (1 + 1.5 + 1.5) = 1020`。此前比值上限设为 1.9 时，绿色阈值为 220 会得到
1056，导致视频流无法启动。修改此配置后，请在工程根目录运行
`python components/Camera/config/validate_awb.py`。

IPA 配置生成器已单独验证，其输出包含 `esp_ipa_awb` 和 AWB 配置指针。这不能证明固件运行
正常或成像效果符合预期。

重新构建并烧录后，请在日光和室内光线下分别对准白色或灰色表面，等待数秒让白平衡稳定，
并检查红、蓝物体。重新打开 Camera 后再重复检查。如果场景中某种饱和颜色占主导，gray-world
AWB 可能会错误估计光源。如果颜色来回变化或偏色加重，请先检查传感器内部白平衡的交互，
再考虑调整各通道增益缩放。需要回退时，重新选择传感器默认的 IPA JSON 配置。
